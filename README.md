## ✨ أبرز مميزات التطبيق

1. **🔒 ويدجيت شاشة القفل التفاعلية (Lock Screen Widgets)**:
   - طبقة شفافة عائمة تظهر مباشرة فوق خلفية شاشة القفل بدون الحاجة لفتح قفل الهاتف.
   - خيار وضع الإخفاء كشريط إشعار يتمدد بلمسة واحدة أو العرض التلقائي الكامل.
2. **📱 9 ويدجات للشاشة الرئيسية بمعاينات حقيقية فائقة الجودة**:
   - معاينات واقعية بدقة عالية تظهر داخل واجهات أندرويد (شاومي HyperOS/MIUI، سامسونج، بكسل) بدلاً من الأيقونة العادية.
3. **👥 نظام متطور لمشاركة وصلاحيات المهام (3 مستويات)**:
   - **مشرف فقط (Supervisor)**: متابعة نسب تقدم الفريق دون تنفيذ مهام شخصية.
   - **مشرف ومنفذ (Supervisor & Executor)**: متابعة وتنفيذ.
   - **منفذ فقط (Executor)**: يرى وينفذ مهامه الموكلة إليه حصراً ولا تظهر له مهام الآخرين.
4. **☁️ مزامنة سحابية شاملة بين جميع الأجهزة و Google Calendar**:
   - مزامنة تلقائية لحظية للمهام والمواعيد والملاحظات بين الكمبيوتر والموبايل وأي جهاز بنفس الحساب.
5. **🎯 مصفوفة أيزنهاور وتخطيط الأولويات**:
   - تقسيم ذكي للمهام (مهم وعاجل، مهم وغير عاجل، عاجل وغير مهم، غير مهم وغير عاجل).
6. **📝 الملاحظات السريعة والمرفقات**:
   - كتابة وتثبيت الملاحظات مع دعم المرفقات والتسجيل الصوتي والتنسيق المتقدم.
