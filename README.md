**مُساعد (MoSa'ed)** هو تطبيق شخصي ذكي ومتكامل لإدارة وتنظيم المهام اليومية، مواعيد التقويم، مصفوفة الأولويات (Eisenhower Matrix)، الملاحظات السريعة والملاحظات الصوتية، مؤقت التركيز والعادات اليومية، بوت الواتساب الذكي باللهجات العربية والإنجليزية، والمزامنة السحابية اللحظية بين جميع أجهزتك (الهاتف، اللابتوب، التابلت) ومع تقويم Google لنفس الحساب تلقائياً.

## 🆕 أبرز تحديثات الإصدار v1.8.0

1. **🔔 مركز الإشعارات والرسائل داخل التطبيق (In-App Inbox)**:
   - أيقونة جرس تفاعلية بعدّاد للرسائل غير المقروءة تجمع تلقائياً المهام المشتركة الواردة، تحديثات تقدم المشاركين، التعليقات المشتركة، وأوامر بوت الواتساب، مع فلاتر وتنقل مباشر.
2. **🤖 بوت الواتساب الذكي وفهم اللهجات (مُساعد أو أي اسم تختاره)**:
   - محرك فهم طبيعي يدعم العربية باللهجات **المصرية والخليجية والشامية والفصحى بالإضافة إلى الإنجليزية** لإضافة الملاحظات والمهام والمواعيد وإتمام المهام أو معرفة مهام اليوم.
   - تخصيص **اسم مختلف للبوت على واتساب** (مثل مُساعد أو Jarvis أو غيره) + استقبال الأوامر تلقائياً عبر إشعارات واتساب على أندرويد مع رد تلقائي + إدخال صوتي باللهجات + رابط Webhook سحابي.
3. **👥 ترقيات المشاركة وتصدير تقارير المشرف**:
   - نظام تعليقات وسجل نشاط حي داخل المهام المشتركة مع تنبيهات فورية للمشرفين.
   - زر **تصدير تقرير المشرف** من لوحة المتابعة بصيغتي **HTML (منسق للطباعة)** و **CSV (متوافق مع Excel والعربية)**.
4. **⏱️ مؤقت التركيز (Pomodoro) + العادات اليومية (Habits) + قوالب المهام**:
   - مؤقت تركيز مرتبط بالمهام مع إحصائيات يومية وإجمالية، متتبع عادات بسلاسل إنجاز يومية (Streaks)، وقوالب مهام جاهزة ومخصصة بضغطة واحدة.
5. **🔒 قفل الخصوصية (PIN) + سلة المحذوفات + البحث الشامل (Ctrl+K) + ترحيل المتأخرات**:
   - قفل الملاحظات والمواضيع الحساسة برمز سري وإخفاء معاينتها، سلة محذوفات لاستعادة المهام والملاحظات والمواعيد، بحث شامل سريع، وزر ترحيل المهام المتأخرة لليوم بلمسة واحدة.
