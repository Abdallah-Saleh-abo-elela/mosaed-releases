**مُساعد (MoSa'ed)** هو تطبيق شخصي وجماعي ذكي ومتكامل لإدارة وتنظيم المهام اليومية، مواعيد التقويم، مصفوفة الأولويات (Eisenhower Matrix)، الملاحظات السريعة والملاحظات الصوتية، مؤقت التركيز والعادات اليومية، بوت الواتساب الذكي باللهجات العربية والإنجليزية، ومشاركة المهام والمواضيع مع المتابعة اللحظية، مع مزامنة سحابية ومحلية مشفرة بطرف-لطرف (E2EE) وتقويم Google.

## 🆕 أبرز مميزات وتطويرات الإصدار v1.9.5

1. **🔄 التحقق التلقائي من التحديثات داخل التطبيق (In-App Update Checker)**:
   - فحص تلقائي خفيف لواجهة GitHub Releases عند فتح التطبيق (كل 12 ساعة) مع زر فحص يدوي في الإعدادات، يعرض تفاصيل التحديث وزر تحميل مباشر متوافق مع نظام تشغيل جهازك مع خيار تخطي الإصدار.
2. **🔒 تشفير بطرف-لطرف للمزامنة والمرفقات (E2EE Cloud & LAN Sync Passphrase)**:
   - طبقة تشفير اختيارية عالية الأمان (`AES-256-GCM` + اشتقاق مفاتيح `PBKDF2-HMAC-SHA256`) بكلمة مرور سرية خاصة بك لتشفير المهام والملاحظات والمواعيد والمرفقات قبل مغادرة جهازك، مع بصمة تحقق مرئية بين أجهزتك ووضع التشفير الصارم واستعادة آمنة دون التأثير على سلاسة مشاركة المهام مع فريقك.
3. **⚡ الانضمام السريع في دقيقة واحدة (1-Minute First-Run Starter Packs)**:
   - قوالب بداية جاهزة حسب طبيعة يومك (طالب / مهندس أو موظف / صاحب عمل حر / استخدام منزلي) داخل الجولة التوضيحية الأولى وفي الإعدادات، لإضافة مواضيع ملونة ومهام بمهامها الفرعية وعادات يومية وقوالب متكررة بضغطة واحدة ودون تكرار.
4. **✨ الذكاء الاصطناعي الاختياري (BYOK AI) وتوسيع بوت الواتساب**:
   - ربط اختياري لمفتاحك الخاص (`Gemini` أو `OpenAI`) في الخزنة الآمنة لتلخيص اليوم (`لخص يومي`), وتقسيم المهام الكبيرة تلقائياً لمهام فرعية من نافذة المهمة، والبحث الدلالي في الملاحظات، وفهم الجمل الحرة في بوت الواتساب — مع الإبقاء على المحلل المحلي السريع مجانياً بالكامل بدون إنترنت كافتراضي.
5. **💾 نسخ احتياطي تلقائي دوري (.json مشفر) على Google Drive أو مجلد محلي**:
   - أخذ نسخة احتياطية دورية أسبوعياً (أو حسب عدد أيام تختاره) بصيغة `.json` (مشفرة بـ `AES-256-GCM` عند تفعيل رمز الحماية أو التشفير) وحفظها تلقائياً في مجلد محلي على جهازك أو داخل مجلد `MoSaed_Backups` في Google Drive الخاص بحسابك مع الاحتفاظ بأحدث 5 نسخ.
