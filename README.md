## 🆕 أبرز تحديثات الإصدار v1.7.0

1. **🤝 تسليم المهام المشتركة داخل التطبيق مباشرةً ولوحة متابعة المشرف (Supervisor Dashboard)**:
   - عند مشاركة مهمة أو موضوع عبر البريد الإلكتروني، تصل المهمة مباشرةً داخل تطبيق الطرف الآخر وتُحدّث حالة الإنجاز لحظياً في الاتجاهين.
   - لوحة متابعة مبسطة ومخصصة للمشرفين تعرض جميع الأشخاص المشارك معهم ونسبة إنجاز كل شخص وكل مهمة (`حسب الأشخاص` و`حسب المهام`).
2. **⚡ مزامنة سحابية لحظية وفائقة السرعة بين الهاتف واللابتوب**:
   - معالجة اختناق المزامنة والضغط الشبكي (`HTTP 429`) وإطلاق مزامنة فورية بمجرد تعديل أو إتمام أي مهمة أو مهمة فرعية.
3. **📎 تخزين ومزامنة حقيقية للمرفقات والصور والتحميل الفعلي على كل جهاز**:
   - رفع المرفقات والصور سحابياً وعبر الشبكة المحلية مع تحميل وحفظ حقيقي للملفات على الهاتف والكمبيوتر وزر فتح مباشر.
4. **🎙️ الملاحظات الصوتية (Voice Notes) عبر الأندرويد والديسكتوب**:
   - تسجيل صوتي مدمج مع عدّاد مباشر ومشغّل داخل البطاقة وزر تسجيل صوتي سريع في شاشة الملاحظات، مع مزامنته وتحميله بين أجهزتك.
5. **🗓️ ميعاد الساعة اختياري للمهام (Day-Only Tasks)**:
   - إمكانية ترك المهمة بدون ساعة (`بدون ساعة (اليوم فقط)`) أو مسح الساعة بضغطة واحدة وإلغاء تنبيه الساعة تلقائياً.

## ✨ أبرز مميزات التطبيق

1. **🔒 ويدجيت شاشة القفل التفاعلية (Lock Screen Widgets)**:
   - طبقة شفافة عائمة تظهر مباشرة فوق خلفية شاشة القفل بدون الحاجة لفتح قفل الهاتف.
   - خيار وضع الإخفاء كشريط إشعار يتمدد بلمسة واحدة أو العرض التلقائي الكامل.
2. **📱 9 ويدجات للشاشة الرئيسية بمعاينات حقيقية فائقة الجودة**:
   - معاينات واقعية بدقة عالية تظهر داخل واجهات أندرويد (شاومي HyperOS/MIUI، سامسونج، بكسل) بدلاً من الأيقونة العادية.
3. **👥 نظام متطور لمشاركة وصلاحيات المهام (3 مستويات)**:
   - **مشرف فقط (Supervisor)**: متابعة نسب تقدم الفريق دون تنفيذ مهام شخصية.
   - **مشرف ومنفذ (Supervisor & Executor)**: متابعة وتنفيذ.
   - **منفذ فقط (Executor)**: يرى وينفذ مهامه الموكلة إليه حصراً ولا تظهر له مهام الآخرين.
4. **☁️ مزامنة سحابية شاملة بين جميع الأجهزة و Google Calendar**:
   - مزامنة تلقائية لحظية للمهام والمواعيد والملاحظات والملفات بين الكمبيوتر والموبايل وأي جهاز بنفس الحساب.
5. **🎯 مصفوفة أيزنهاور وتخطيط الأولويات**:
   - تقسيم ذكي للمهام (مهم وعاجل، مهم وغير عاجل، عاجل وغير مهم، غير مهم وغير عاجل).
6. **📝 الملاحظات السريعة والمرفقات والتسجيل الصوتي**:
   - كتابة وتثبيت الملاحظات مع دعم الصور والملفات والتسجيل الصوتي والتنسيق المتقدم.
