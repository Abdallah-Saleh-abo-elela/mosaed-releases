**مُساعد (MoSa'ed)** هو تطبيق شخصي وجماعي ذكي ومتكامل لإدارة وتنظيم المهام اليومية، مواعيد التقويم، مصفوفة الأولويات (Eisenhower Matrix)، الملاحظات السريعة والملاحظات الصوتية، مؤقت التركيز والعادات اليومية، بوت الواتساب الذكي باللهجات العربية والإنجليزية، ومشاركة المهام والمواضيع مع المتابعة اللحظية، مع مزامنة سحابية ومحلية فورية بين جميع أجهزتك وتقويم Google.

## 🆕 أبرز تحسينات وتطويرات الإصدار v1.9.0 (إصدار الاعتمادية والإطلاق)

1. **🔄 مزامنة أذكى لمشاركة المهام والمشرفين + عدم ضياع أي تقدم**:
   - حساب أدق لنسبة الإنجاز عبر المهام الموزعة والمهام الفرعية مع دمج تجميعي (`Union Merge`) لتقدم كل مشارك عند التعديل المتزامن، ومزامنة إتمام المهام الفرعية والأساسية مع قاعدة البيانات المحلية، وإشعارات حية للمشرف فور إنجاز المشاركين.
2. **☁️ مزامنة كاملة لأدوات الإنتاجية والخصوصية عبر الأجهزة**:
   - دمج ذكي (`mergeJsonListById` + اتحاد أيام سلاسل العادات) لسجل جلسات التركيز والعادات اليومية وقوالب المهام وصندوق الرسائل ورمز القفل (`PIN`) عند الاستعادة أو المزامنة بين الهاتف واللابتوب دون الكتابة فوق البيانات الموجودة.
   - الحفاظ الكامل على إعداد التذكير المستمر/المتكرر (`nagging_interval_minutes`) للمهام والملاحظات والمواعيد أثناء المزامنة السحابية والمحلية.
3. **🔔 نظافة التنبيهات والتكرار المستمر والفتح المباشر (Deep Linking)**:
   - إلغاء إشعارات نظام التشغيل تلقائياً عند إتمام أو حذف أي مهمة أو موعد لمنع التنبيهات الشبحية.
   - الضغط على أي إشعار يفتح الشاشة المرتبطة مباشرة (المهام، التقويم، الملاحظات، المواضيع).
   - توليد المهمة المتكررة التالية تلقائياً عند إتمام المهمة المتكررة الحالية (مع استنساخ مهامها الفرعية غير المكتملة) ودعم قواعد التكرار بغض النظر عن حالة الأحرف.
4. **🤖 دقة أعلى لمحلل الأوامر الذكي وبوت الواتساب**:
   - فصل دقيق بين الكميات والأرقام الترتيبية (مثل `"شراء 2 مساطر"`) وبين أوقات الساعة الفعلية، دعم التواريخ قبل الساعة (مثل `"يوم 15/11 الساعة 4 العصر"`), تنظيف أفضل للعنوان من حروف الجر وكلمات الوقت والأولوية، ودعم استعلام مهام/مواعيد الغد (`"مهام بكرة"` / `"what do I have tomorrow"`).
5. **🎨 سلاسة وتجاوب الواجهة (عربي RTL / إنجليزي LTR + الكمبيوتر والهاتف)**:
   - إصلاح انزياح التكبير/التصغير على الديسكتوب حسب اتجاه اللغة (`RTL` / `LTR`)، الحفظ التلقائي لأي مهمة فرعية أو عنصر قائمة لم يُضغط فيه زر الإضافة قبل الحفظ، وإصلاح أي Overflow على الشاشات الضيقة بالعربية مع خطوط كبيرة، وإضافة ترجمة إنجليزية كاملة لأزرار الإجراءات السريعة.
